# Kokoro ONNX speech model

The exact original Kokoro ONNX voice model used for this film is archived
as **kokoro-v1.0.onnx** and **voices-v1.0.bin** on GitHub Release v1.0.0.

Download both release assets into this directory to regenerate narration:
- kokoro-v1.0.onnx
- voices-v1.0.bin

Both original model files are under the upstream Kokoro Apache 2.0 license.
Project: https://huggingface.co/hexgrad/Kokoro-82M
ONNX conversion: https://github.com/thewh1teagle/kokoro-onnx

The final voice WAVs are already in public/audio/; voice regeneration is optional.
